OFF

The Companion runs in the background. Start pairing to create your phone QR; no setup window needs to stay open.

One-time setup
  1. Copy your extension ID, then open FFmpeg_Helper and run setup_remote.bat. Paste the ID when asked.
  2. Allow the Private-network firewall rule. On your trusted home Wi-Fi, set Windows Settings → Network & Internet → Wi-Fi → your network → Network profile to Private.
  3. Return here and choose Check connection, then Start pairing. Keep your phone on the same non-guest Wi-Fi.
Already installed? Check connection first. If it fails, run check_remote.bat for a read-only diagnosis.
