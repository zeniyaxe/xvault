# XVault

XVault v16.0.0 Chrome extension.

Download and extract XVault.zip. Open chrome://extensions, enable Developer mode, choose Load unpacked, and select the XVault folder containing manifest.json.

For updates, reload the same extension installation to preserve local data.

Optional GIF/WebP helper: run FFmpeg_Helper/setup_helper.bat then FFmpeg_Helper/run_helper.bat. Remote setup: FFmpeg_Helper/REMOTE_README.md. Use config.example.json for local configuration.

Personal configuration, credentials, state, logs, screenshots, browser profiles and development notes are excluded.
